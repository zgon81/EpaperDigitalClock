# Użyte źródła bibliotek

Nie wyszukiwano identyfikatorów Context7. Projekt korzysta ze standardowych bibliotek Arduino (`Arduino.h`, `SPI.h`, `WiFi.h`) oraz API czasu, SNTP i deep sleep ESP-IDF dostarczanych przez PlatformIO. Nie dodano zewnętrznych bibliotek firmware. Sprawdzono lokalne `esp32-hal-time.c` i `esp_sntp.h` frameworka Arduino-ESP32 2.0.17.

Font wygenerowany z lokalnego DejaVu Sans Mono; skrypt developerski używa Pillow, firmware nie wymaga dodatkowych bibliotek.
